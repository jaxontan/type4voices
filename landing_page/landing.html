Install

Windows

Python 3.12, PATH on

windows\setup.bat
.venv\Scripts\python.exe download_model.py
windows\run_dictate.bat
# no console window: windows\run_dictate_background.vbs

macOS

Python 3.12, python.org

cd macos
chmod +x *.sh run_dictate.command
./setup.sh
cd ..

.venv/bin/python download_model.py
./macos/run_dictate.sh
# then allow Microphone, Accessibility, Input Monitoring

Linux

X11 session, PortAudio

sudo apt install python3-venv python3-tk libportaudio2 xclip

cd linux
chmod +x *.sh
./setup.sh
cd ..

.venv/bin/python download_model.py
./linux/run_dictate.sh
# Wayland will not work

Limits

Wayland
Blocks global hooks, synthetic keys and tray icons. Use X11 or Xorg.
Admin windows
Windows blocks synthetic keys into elevated windows. Restart as Administrator from the tray.
macOS and Linux
Written, not run yet. Windows is the tested build.
