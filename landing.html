Systems Engineering

How desktop dictation actually works without cloud APIs.

Most voice apps wrap an external cloud STT API in an Electron browser shell. type4voices is written in native Python with low-level OS hooks, PortAudio ring-buffers, and in-process PyTorch inference.

1. Event Swallowing (WH_MOUSE_LL)

trigger.py

If you map your mouse's Forward button (XButton2) using conventional listeners, Windows will still pass the event to your browser, accidentally navigating forward in your history. type4voices installs a genuine WH_MOUSE_LL Windows hook that consumes the event at kernel dispatch, returning 1 to swallow it completely.

def _low_level_mouse_proc(nCode, wParam, lParam): if nCode >= 0: btn = _decode_xbutton(lParam) if btn == target_button: _dispatch_async(wParam) # never blocks hook return 1 # SWALLOW: browser never navigates return CallNextHookEx(None, nCode, wParam, lParam)

2. Non-Activating Focus Guard

overlay.py

When synthetic keystrokes (like Ctrl+V or Cmd+V) are fired, they land in whichever window has OS keyboard focus. If your transcript overlay window takes focus for even 1 millisecond, the paste drops into the void. type4voices applies WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW on Windows and non-activating NSPanel on macOS.

# Win32 window creation: never steal focus style = GetWindowLong(hwnd, GWL_EXSTYLE) SetWindowLong(hwnd, GWL_EXSTYLE, style | WS_EX_NOACTIVATE | WS_EX_TOOLWINDOW) SetWindowPos(hwnd, HWND_TOPMOST, 0, 0, 0, 0, SWP_NOMOVE | SWP_NOSIZE | SWP_NOACTIVATE)

3. Strict Network Isolation

MODEL_NOTES.md

The model weights (Qwen3-ASR-1.7B, ~4.4 GB or 0.6B, ~1.2 GB) download once via download_model.py. Once cached, dictate.py boots with:

os.environ["HF_HUB_OFFLINE"] = "1" os.environ["TRANSFORMERS_OFFLINE"] = "1" os.environ["HF_HUB_DISABLE_TELEMETRY"] = "1"

Any attempt by underlying libraries to check for updates or phone home causes an immediate local error instead of transmitting metadata.

4. Serialization & Audio Pipeline

dictate.py

Sound frames arrive at 16,000 Hz float32 from PortAudio. Short clicks under min_seconds (1.0s) are discarded to eliminate accidental mic clicks. Transcriptions queue through a single worker thread so rapid dictations never compete for CPU inference cores.

16kHz Audio Stream ──> Ring Buffer ──> Trim Silence (RMS threshold) │ └──> Job Queue (FIFO) ──> Qwen3-ASR CPU Model ──> text_cleanup() │ Paste (Ctrl+V) <──────────┘

Installation

Five minutes once. Offline forever.

No signups, no API keys, no monthly fees. Clone or copy the folder, run setup once to download model weights, and run it.

PowerShell / Command Prompt 
# 1. Install Python 3.12 (check "Add python.exe to PATH")
# 2. Run automated setup (creates .venv and installs dependencies)
windows\setup.bat

# 3. Download the Qwen3-ASR model once (4.4 GB, cached locally)
.venv\Scripts\python.exe download_model.py

# 4. Start foreground console or invisible background daemon
windows\run_dictate.bat            # with console log
windows\run_dictate_background.vbs # silent tray only

# 5. Verify microphone, model weights, and low-level hook

./linux/run_dictate.sh
Technical FAQ

Common developer questions.

Does my voice or transcript ever leave my machine?
No. The application runs with HF_HUB_OFFLINE=1 and TRANSFORMERS_OFFLINE=1 locked at the Python process root. Audio frames are held in memory as float32 NumPy arrays, fed directly into the local Qwen3-ASR model, and converted to text in RAM. You can inspect the network connections with Wireshark or NetLimiter: once the model is downloaded, zero network sockets are opened.
Why does the mouse Forward button not trigger browser back/forward?
On Windows, trigger.py installs a native WH_MOUSE_LL callback via the Windows API. When the mouse side button (XButton2) is detected, the callback handles the recording state machine and returns non-zero (1). This consumes the message from the Windows message pump, preventing it from reaching Chrome, Edge, or Firefox.
How does the transcript paste into the right window?
The transcript overlay and clipboard history panels are created as Win32 WS_EX_NOACTIVATE tool windows (and macOS non-activating NSPanel). They never take keyboard focus from whatever application is active. When you release the shortcut, the app places the transcript onto the system clipboard and dispatches a synthetic Ctrl+V (or Cmd+V), which lands directly at your active cursor.
Can I use technical domain jargon or colleague names?
Yes. Add one phrase per line to hotwords.txt (e.g. Kubernetes, PostgreSQL, OAuth2, Guangdong). These terms are passed directly into the model context prompt to bias speech recognition accuracy. The file is hot-reloaded automatically when saved.
What happens if I dictate into an Administrator/Elevated window?
Windows User Interface Privilege Isolation (UIPI) blocks non-elevated applications from sending synthetic keystrokes to elevated (admin) windows. If you need to dictate into elevated command prompts or admin tools, use the tray icon menu item: Restart as Administrator.
Why is Linux restricted to X11 sessions instead of Wayland?
Wayland security architecture explicitly forbids unprivileged background processes from intercepting global mouse/keyboard events, injecting synthetic keystrokes into other windows, and rendering arbitrary system tray icons. type4voices works natively on X11/Xorg sessions. Running dictate.py --doctor will report which display server session is active.
