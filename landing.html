Windows, macOS and Linux

Speak. It lands at the cursor.

Hold the Forward mouse button, talk, let go. Qwen3-ASR types the sentence into the window that already had focus, on your own CPU, with no network.

Python 3.10+ · 4.4 GB model, downloaded once

What it does

Talk
Hold to record, release to paste. Under a second is ignored.
Lamps
  • Idle
  • Working
  • Paused
Panel
Timer, then the transcript. Click it for history.
Clipboard
Left-click the tray icon for the last five copies.
Cleanup
Spoken numbers and punctuation are typed as characters.
Recorder
Any key, chord or click, applied on the spot: F8, Ctrl+Alt+J.
Windows
The side button stops navigating the browser.

One process, no server

The same Python runs on all three systems. The OS quirks live in one file.

hold     record
release  transcribe, clean, paste
paste    keep for the clipboard popup

Windows swallows the shortcut before the app sees it. macOS and Linux only watch, so the key still reaches whatever is behind.

Install once

Python 3.10+, a microphone, 6 GB of disk.

Windows

Python 3.12, PATH enabled

windows\setup.bat
.venv\Scripts\python.exe download_model.py
windows\run_dictate.bat
# no console window:
# windows\run_dictate_background.vbs

macOS

Python 3.12 from python.org

cd macos
chmod +x *.sh run_dictate.command
./setup.sh
cd ..

.venv/bin/python download_model.py
./macos/run_dictate.sh
# then allow 3 macOS permissions
# and restart the app

Questions

Does anything leave the machine?

No. The model is downloaded once, then the app runs with the network off.

Why did the side button stop going Back?

On Windows the hook takes the click before the browser sees it. macOS and Linux can only watch, so pick something unused there.

Where does the text go?

Onto the clipboard, then Ctrl+V or Cmd+V at the caret in the focused window.

Why X11 and not Wayland?

Wayland blocks global hooks, synthetic keys and tray icons for ordinary apps.

Can I use a different shortcut?

Tray, Shortcut, Detect, then press it. A bare letter is refused; Ctrl+Alt+J works immediately.

Names and jargon?

Add one term per line to hotwords.txt. It reloads when the file changes.
